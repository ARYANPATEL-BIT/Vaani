Interrupting

Silence first. Everything else after.

When you speak over Vaani, three things happen in a fixed order. You hear it stop before the system has finished cleaning up.

  1. 01

    It hears you start

    Speech detection runs on the CPU. Nothing on this path makes a network call, so noticing you never waits on the internet.

  2. 02

    Playback is flushed

    The audio already queued in your browser is thrown away first. That is the moment the voice goes quiet.

  3. 03

    The work is cancelled

    One cancel signal stops the speech synthesis and closes the stream from the language model, so nothing keeps running in the background.

Runs on a CPU

The default setup needs no graphics card. A GPU is an option, not a requirement.

Everything can be cancelled

Every model call and long task carries a stop signal, and stopping closes the network stream cleanly.

Vendors are settings

Model providers sit behind one adapter and are chosen in configuration, so swapping one never means rewriting the app.

Spend is capped

The spending limit is checked before any paid call is sent, not after the bill arrives.
