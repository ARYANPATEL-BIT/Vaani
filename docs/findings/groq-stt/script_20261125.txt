observations
- The romanized prompt is what turned turbo's output Latin: turbo with no
  prompt (a) wrote Devanagari. large-v3 wrote Devanagari with the prompt (b)
  and without it (c), as large-v3 does locally on the GPU
  (docs/spikes/asr-hinglish.md, Sample B).
- Text quality, read against the suggested sentence (whether it was read
  word for word is not confirmed): b is the closest, the only one with
  "सुबह" spelled correctly (a and c wrote "सुबा"). All three
  wrote "किरपया" for "कृपया" and "टिकेट" for "टिकट". No stray characters.
- "c" took 662 ms against b's 373 ms on the same model; with n = 1 that gap
  says nothing about the models; its cause was not looked into.
- Not tested here: Hinglish audio. The prompt exists to keep the ENGLISH
  words of Hinglish in Latin letters; this clip has no English words, so it
  cannot show what dropping the prompt costs on Hinglish.
- No errors, no 429; no key-like string appeared in any output.
